# Форма стекла — steklaaa

Сайт-каталог мастерской «Форма стекла»: подбор и изготовление термостойких стекол для духовых шкафов и кухонных плит по модели и размерам.

## Демо на GitHub Pages
После публикации сайт доступен по адресу:
👉 **https://punelittley.github.io/steklaaa/**

## Особенности
- Интерактивная 3D-модель трёхслойного стеклопакета духовки
- Конфигуратор вариантов рамки (чёрная, белая, прозрачная)
- Инженерная схема подбора деталей с хотспотами
- Галерея работ мастерской с фильтрами и полноэкранным просмотром (Lightbox)
- Интерактивный слайдер сравнения «До / После замены»
- Форма формирования заявки с копированием в буфер обмена
