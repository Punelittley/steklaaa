## Ассортимент и особенности
- **Стекла для духовых шкафов:**
  - Внешние (отверстия под ручку и петли, широкая покраска термостойкой краской **стемалит** в чёрный или белый цвета со смотровым окном, либо качественная **тонировочная плёнка**)
  - Внутренние (с термостойкой покраской **стемалит** и вырезами под фиксаторы, либо **полностью прозрачные жаропрочные** со скошенными углами и радиусными вырезами под петли)
  - Промежуточные / средние (термоизоляционный закаленный слой)
- **Стекла для плит и керамических поверхностей** (по размерам и вырезам под конфорки)
- **Жаропрочные стекла для СВЧ-печей (микроволновок)**
- **Полки для холодильников из закаленного стекла** по точным размерам с еврокромкой
