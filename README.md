## Ассортимент и особенности
- **Закалённые стёкла для духовых шкафов и плит:**
  - Внешние стёкла с отверстиями под ручку двери (покраска стемалит в чёрный/белый цвет, смотровое окно или тонировка)
  - Внутренние стёкла (с покраской стемалит или прозрачные)
  - Промежуточные (средние) стёкла — прозрачные или с покраской, с прямыми углами
  - Стёкла для панелей управления с отверстиями под поворотные регуляторы
- **Полки для холодильников из закаленного стекла** 4–6 мм с полированной еврокромкой
- **Душевые ширмы и перегородки** из закаленного безопасного стекла 6–10 мм
- **Изделия из жаропрочной стеклокерамики** (до 750°C) для варочных панелей, каминов и печей
- **Стёкла для СВЧ-печей (микроволновок)**
