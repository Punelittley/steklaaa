# Форма стекла — steklaaa

Сайт-каталог мастерской «Форма стекла»: изготовление жаропрочных стекол для всех видов духовых шкафов, плит, СВЧ-печей, керамических поверхностей, полок холодильников и др.

## Демо на GitHub Pages
👉 **https://punelittley.github.io/steklaaa/**

## Ассортимент и особенности
- **Стекла для духовых шкафов:**
  - Внутренние (максимальная жаропрочность)
  - Промежуточные / средние (термоизоляционный слой)
  - Внешние (окрашивание по периметру термостойкой краской **стемалит** в чёрный или белый цвета, либо покрытие **тонировочной плёнкой с вырезом под смотровое окошко**)
- **Стекла для плит и керамических поверхностей**
- **Жаропрочные стекла для СВЧ-печей (микроволновок)**
- **Полки для холодильников из закаленного стекла** по точным размерам
